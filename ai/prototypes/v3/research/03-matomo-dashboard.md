# Matomo Web Analytics Dashboard — Research Summary

## Overview
Matomo is a comprehensive web analytics platform with customizable dashboards. It groups metrics into logical categories: traffic, engagement, audience, acquisition, behaviour, and goals/ecommerce.

## Dashboard Types

### Overview Dashboard
Comprehensive snapshot of key metrics and KPIs:
- **Traffic metrics**: Total sessions, visits, distinct users, total pages viewed, average pages per visit
- **Engagement metrics**: Average session duration, bounce rate, exit rate by page
- **Audience metrics**: New vs. returning visitors, visitor demographics (age, gender, location), device types (desktop, mobile, tablet)

### Acquisition Dashboard
How users arrive at the website:
- Traffic source breakdown: organic search, social platforms, direct URL, referrals, paid advertising
- Campaign performance measurement
- Channel type grouping
- UTM-tagged campaign tracking
- Search engine and keyword reporting
- Multi-channel conversion attribution

### Behavioural Dashboard
How users interact with the site:
- Most/least trafficked pages
- Time spent before leaving
- User engagement, navigation, page flow analysis
- Scroll depth, click patterns
- Form completion rates, event tracking
- Heat maps, click maps, user path diagrams
- Content performance identification (engaging vs. underperforming)

### Goals and Ecommerce Dashboard
- **Goal tracking**: Completed user actions (form submissions, sign-ups, downloads)
- **Funnel analysis**: Conversion rates, drop-off points
- **Revenue tracking**: Sales figures, average order value, top-selling items, revenue per product, refund rates
- **Shopping behaviour analysis**: Browsing → cart abandonment → purchase flow
- **Conversion attribution**: Which traffic sources drive most conversions

### Custom Segments Dashboard
- Analyze specific audience subsets based on criteria
- Segment by acquisition data, demographics, behaviour
- Compare segments

## Key KPIs
| Category | Example Metric | Business Question |
|---|---|---|
| Traffic | Sessions, visits, distinct users | How much traffic? |
| Engagement | Avg session duration, bounce rate | Is content engaging? |
| Audience | New vs returning, device type | Who are visitors? |
| Acquisition | Channel breakdown, campaign performance | Where do visitors come from? |
| Behaviour | Top pages, exit rates | What do visitors do? |
| Conversion | Goal completion, conversion rate | Are goals being met? |

## Dashboard Customization
- Customizable widgets and layout
- Multiple dashboards for different user roles
- Share custom dashboard templates
- Email marketing and campaigns dashboard example
- Content marketing and SEO dashboard example
- Widget types: KPI metric widget, custom reports, SEO ranking widget

## Design Principles
- Put most important metrics first (5-second health check)
- Group related metrics together
- Customizable for different use cases (director vs. marketing team)
- Multiple dashboard configurations for different roles
