# GA4 Complete Guide 2025 — Research Summary

## Overview
Google Analytics 4 is Google's current analytics platform using an event-based tracking model. It replaced Universal Analytics. Emphasizes customization with fewer pre-built reports but more powerful analysis tools.

## Data Model
- **Events**: Every interaction tracked as an event (page_view, click, purchase)
- **Parameters**: Additional data attached to events (page_title, item_name)
- **User Properties**: Attributes describing user segments (country, device)
- **Conversions**: Events marked as important business outcomes
- **Data Streams**: Sources of data (web, iOS, Android)

## Interface & Reports

### Home Dashboard
- User count over last 7 days
- Total conversions
- Event count
- Session count
- Real-time users (last 30 minutes)
- Customizable overview

### Realtime Report
- Active users
- Events firing
- Conversions happening
- Traffic sources
- Map visualization of visitor locations
- Page titles currently being viewed

### Life Cycle Reports

#### Acquisition Reports
- How users land on the website
- Users, new users, sessions
- First user source, traffic channels
- Campaign performance (UTM)

#### Engagement Reports
- **Overview**: Engaged sessions, engagement rate, engaged sessions per user, average engagement time
- **Events**: All events with counts (page_view, session_start, first_visit, scroll, click, file_download)
- **Conversions**: Events marked as conversions, toggle any event to conversion
- **Pages and Screens**: Views, users, average engagement time per page
- **Landing Pages**: Entry points with traffic source data and conversion rates

#### Monetization Reports
- Revenue, purchases, checkout behaviour, top-selling items

#### Retention Reports
- User return rates, cohort analysis

### Demographics & Tech
- User demographics (age, gender, location)
- Device and browser breakdown

## Explore Section (Advanced Analysis)
Seven distinct techniques:

1. **Free Form**: Blank canvas, add any dimensions/metrics. Up to 20 dimensions, 6 visualization types (table, bar, scatter, line, pie, geo).
2. **Funnel Exploration**: Step-by-step conversion funnels (up to 10 steps). Open or closed funnel. Elapsed time. Segment comparisons.
3. **Path Exploration**: Clickstream tree from any event forward or backward (up to 10 steps). The only native UI way to do clickstream analysis.
4. **Segment Overlap**: Compare audience segments for common characteristics.
5. **Cohort Exploration**: Group users by acquisition date, compare behavior over time.
6. **User Lifetime**: Analyze behavior changes over user lifetime.
7. **User Exploration**: Individual-user debugging.

## Automatically Tracked Events (Enhanced Measurement)
- Page views
- Scrolls (90% of page)
- Outbound clicks
- Site search
- Video engagement (YouTube embeds)
- File downloads
- Form interactions (starts and submissions)

## Key Metrics
- **Engaged Sessions**: Sessions lasting 10+ seconds OR 2+ pageviews OR triggering conversion
- **Engagement Rate**: Engaged sessions / total sessions (GA4's version of bounce rate inverse)
- **Average Engagement Time**: Time users actively engage

## Design Principles
- Customization over pre-built reports
- Event-based model for flexibility
- Cross-platform tracking (web + apps)
- Fewer standard reports, more exploration tools
- Put most important KPIs at the top
